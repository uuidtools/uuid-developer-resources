# UUID Code Examples

Practical UUID examples for developers using different programming languages and databases.

## Available Examples

### PHP

Generate UUID v4 identifiers using PHP.

See:

`php/uuid-v4.php`

### JavaScript

Generate UUID v4 identifiers using the browser Web Crypto API.

See:

`javascript/uuid-v4.js`

### Node.js

Generate UUID v4 identifiers using Node.js.

See:

`nodejs/uuid-v4.js`

### Python

Generate UUID v4 identifiers using Python.

See:

`python/uuid-v4.py`

### MySQL

Basic UUID usage with a MySQL table.

See:

`mysql/uuid-examples.sql`

## Online UUID Tools

You can also generate, validate and format UUIDs online:
